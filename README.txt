CASHFLOW PROTOTYPE
===================
Fitur:
1. PEMASUKAN - tanggal, nominal, keterangan, simpan, edit, hapus.
2. PENGELUARAN - tanggal, nominal, keterangan, simpan, edit, hapus.
3. RINCIAN - total pemasukan, total pengeluaran, saldo bersih, dan rincian transaksi.

Data tersimpan di localStorage browser/perangkat.
Tema: ungu tua + merah muda + biru muda.
Sudah termasuk splash screen, icon, PWA manifest, dan service worker.

Cara pakai:
- Buka index.html untuk mencoba di browser.
- Untuk instalasi sebagai PWA, host folder ini di HTTPS (misalnya GitHub Pages).
